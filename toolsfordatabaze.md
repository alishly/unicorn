# Инструменты для работы с базами данных

---

## DBeaver

 Универсальный кросс-платформенный клиент с открытым исходным кодом

**Поддержка:** реляционные СУБД через JDBC, а также NoSQL (MongoDB, Redis и др.)

**Особенности:**
- редактор SQL
- визуальный редактор таблиц
- построение ER-диаграмм


## DataGrip (JetBrains)

Коммерческое интегрированное средство для разработчиков

Поддерживает множество СУБД 

**Особенности:**

- глубокий анализ SQL
- интеллектуальное автодополнение с учётом структуры БД
- рефакторинг
- интеграция с системами контроля версий


## pgAdmin

Клиент для PostgreSQL (веб-приложение или настольная версия)

**Особенности:**
- выполнение SQL-запросов
- управление ролями пользователей
- мониторинг производительности


## MySQL Workbench

Официальный клиент для MySQL

**Особенности:**
- визуальное моделирование данных
- инструменты миграции
- профилировщик запросов


## MongoDB Compass

Графический интерфейс для MongoDB

**Особенности:**
- визуальное построение агрегаций
- просмотр документов
- анализ схем данных
- управление индексами



## Redis Insight

Официальный клиент для Redis

**Особенности:**
- просмотр ключей разных типов
- анализ использования памяти
- выполнение команд через консоль



## ORM (Object-Relational Mapping)

 преобразование таблиц реляционных баз данных в объекты языка программирования


- запросы пишутся в виде цепочек методов
- автоматическая трансляция в SQL
- упрощение смены СУБД

**Особенность:** при неаккуратном использовании могут генерироваться неоптимальные по производительности запросы
