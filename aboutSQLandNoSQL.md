# Базы данных   
**Базы данных** - набор каких то данных, которые структурированны.

**Система управления базами данных (СУБД)** - это системы (или программы), позволяющие создавать базы данных и манипулировать сведениями из них.   

Когда мы, как пользователи, хотим получить данные, хранящиеся в базе данных, мы формируем запрос на языке SQL. Система управления базами данных принимает этот запрос и обращается к БД для поиска нужной информации. После того как данные найдены, СУБД возвращает их нам, и мы можем их просмотреть.

#### Типы баз данных

- Реляционные;

- Нереляционные (NoSQL);

- Объектно-ориентированные;

- Иерархические;

- Сетевые;

- NewSQL.
  
## Реляционные базы данных   

#### Особенности

- Жесткая структура

- Табличное представление

- Вертикальное масштабирование

- Связи через ключи

- SQL-запросы

### PostgreSQL   

#### Основные особенности:

- Является бесплатной и имеет открытый исходный код

- Строгое соответствие стандартам SQL

- Полностью соблюдает ACID (атомарность, согласованность, изолированность, долговечность)

1. Атомарность: транзакция либо выполняется целиком, либо не выполняется вовсе.

2. Согласованность: данные всегда остаются в валидном состоянии.

3. Изолированность: параллельные операции не влияют друг на друга (благодаря механизму MVCC — многоверсионному параллелизму).

4. Долговечность: даже при сбое питания данные не теряются
   
- Наследование таблиц

- Расширяемость через модули: PostGIS (геоданные), pgvector (AI/эмбеддинги), TimescaleDB (временные ряды)

- Поддержка разных типов данных в том числе  JSON

- Разнообразные индексы: B-Tree, GIN, GiST, BRIN

  
### MsSQL 

#### Основные особенности:

- Разработчик: Microsoft
  
- полностью поддерживает ACID

- Использует механизм MVCC

- Использует T-SQL (Transact-SQL) — расширение SQL с поддержкой Переменных, Условной логики,  Циклов, Обработки ошибок
Хранимых процедур, функций, триггеров

### Maria DB

#### Основные особенности:

- Открытый исходный код

- Форк MySQL, создан после покупки MySQL компанией Oracle

- Полная совместимость с MySQL

- Поддержка работы с JSON

- Совместима с PostgreSQL, SQL Server


## Нереляционные базы данных   

Особенности Нереляционной БД

- Нет требований к структуре

- Вертикальное и горизонтальное масштабирование

- Различные алгоритмы запросов

- Высокая защита
  

### MongoDB

#### Основные особенности:

- Хранение данных в формате "ключ": "значение"

- Документы в формате JSON (BSON) , а не таблицы и строки

### ClickHouse

#### Основные особенности:

- Колоночное хранени

- Рабоает на SQL

### Redis

#### Основные особенности:

-Данные хранятся в формате пар «ключ — значение» 

- удовлетворяет требованиям ACID
